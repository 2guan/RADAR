# [hengguan/REQ-20260803-009] 配置属性值存储与显示值展示统一

## 0. AI 执行约束

- 所有来源于配置/字典/主数据的受控字段，持久化、筛选、权限和内部关联使用稳定属性值（或系统编号、人员 ID 等稳定键）；页面、导出和可读快照使用对应显示值。
- 导入接受属性值或显示值，并在服务端解析为属性值；歧义、未知或空值不得静默写入显示值。
- 重点修复所属机构、实施机构、组织机构：`org` 字典的 `attr_value` 是唯一存储与权限比较值，`display_value` 只用于用户可读展示。
- 盘点并修复种子、mock、迁移夹具和测试中直接写入显示值的受控字段；为已存在环境追加 SQLite 与 TDSQL/MySQL 8 的幂等兼容迁移，不改写历史迁移。
- 不改变自由文本、编号、日期、投产点、附件路径、状态机、角色定义或 API 包装结构；不把配置显示值回写为业务存储值。

## 1. 目标与业务价值

- 要解决的问题：配置项的属性值与显示值在页面、导入导出、机构权限和 seed/mock 中混用，导致短名称被写入业务字段、筛选/权限比较不稳定，以及导出内容不易读。
- 预期结果：受控配置字段“存属性值、显显示值、导入可识别二者、导出只给显示值”；机构相关字段在系统、人员、需求、工单、开发、测试、投产、概览、仪表盘和动态字段中遵循同一规则。
- 业务价值：管理员可以调整显示文案而不破坏历史业务关联；用户看见统一的业务名称；导入导出和数据权限具备可预测、可审计的口径。

## 3. 范围

### 本次要做

1. 建立并复用服务端“受控值解析/显示映射”公开能力，区分字典、机构、系统和人员；业务写入、导入、动态字段值、筛选与权限均保存/比较稳定键。
2. 盘点 `web/src`、`server/src`、导入导出及动态字段：列表、详情、表单反显、筛选标签、仪表盘、概览、顶栏和 Excel 导出一律显示显示值；选择器的 value 为属性值。版本概览需求/工单卡片标题下的两个标签独立于卡片分组机构：未选择主责系统时显示“未确定主责系统”，已选择时显示所选主责系统；第二个标签始终显示需求/工单填写的实施机构。
3. 对 `org` 机构配置及所属机构、实施机构、组织机构字段完成端到端修复：包括人员组织、系统所属机构、需求/工单/开发/测试/投产字段、权限比较、动态值快照和导入导出。
4. 修正种子、mock、测试夹具和默认配置中直接写显示值的受控值；新增 SQLite/TDSQL/MySQL 8 幂等迁移，将能够无歧义映射的历史显示值转换为属性值，保留无法映射值并输出可追踪错误/风险。
5. 为“存属性/显显示/导入解析/导出显示/旧显示值兼容/机构数据范围/迁移幂等”补齐自动化覆盖，并进行浏览器验收。

### 明确不做

1. 不将自由文本、日期、投产点、系统编号、人员 ID、附件、状态机或 API 外层响应改为显示值。
2. 不删除、合并或重命名现有字典项；显示值可编辑能力和既有字典管理权限不变。
3. 不访问或修改生产数据；存量修复仅通过随应用发布的可回退数据库迁移执行。

## 4. 行为与业务规则

- 当前行为：部分选择器值为属性值，但列表/详情/导出直出属性值；部分 seed/mock 直接把机构显示值写入组织或业务字段，历史值兼容与权限比较依赖多值兜底。
- 变更后行为：每个受控字段存在明确的 `storageValue` 与 `displayValue`。服务端先解析输入为稳定值再写库；读模型与导出映射显示值；API 仍传递兼容的原字段和展示字段，不破坏既有客户端。
- 失败行为：未知/歧义显示值在受保护写入与导入中返回字段级错误，不落库；历史无法映射值不自动猜测、迁移保留原值并记录为已知风险。

| 规则编号 | 触发条件 | 业务规则 | 不满足时处理 |
| --- | --- | --- | --- |
| BR-001 | 保存受控配置字段 | 数据库存属性值/稳定键 | 服务端解析失败则拒绝写入 |
| BR-002 | 页面、详情、筛选标签或导出展示 | 输出对应显示值 | 缺失映射时回退原值并保留可追踪告警/风险 |
| BR-003 | 导入属性值或显示值 | 统一解析为属性值后写入 | 未知或歧义行提供字段、原值和错误原因 |
| BR-004 | 机构字段与数据范围比较 | 使用 `org.attr_value` | 仅在读取旧值时兼容显示值，禁止新写入 |
| BR-005 | 动态字段受控选择 | `value_code`/`value_ref_id` 保存稳定键，`value_label_snapshot` 保存显示值 | 读取与导出使用快照/当前显示映射，不回写显示值到值列 |
| BR-006 | 种子、mock 与迁移 | 受控字段直接写属性值 | 发现显示值直写时修正并以测试防回归 |

## 6. 权限、审计与外网

| 角色 | 查看/新增/修改/动作 | 数据范围 | 内网/外网 |
| --- | --- | --- | --- |
| 既有授权用户 | 沿用各模块查看、编辑、导入和导出权限 | 机构按属性值过滤 | 内网 |

- 无权限处理：服务端 RBAC 和机构数据范围继续拒绝 `401/403`；显示映射不得绕过数据范围。
- 审计要求：沿用配置和业务写入审计；审计可读文本显示显示值，原始变更保持稳定值可追溯。
- 外网开放场景、字段、动作、附件限制与禁止项：不涉及。
