# [hengguan/REQ-20260803-007] 全系统日期时间格式与北京时间统一

## 0. AI 执行约束

- 仅实施本需求的日期、时间显示与“当前日期/时间”计算统一；不改变业务日期字段的存储格式、数据库 schema、状态流转、权限、审计语义或 API 响应结构。
- 日期展示的默认格式固定为 `YYYY-M-D`（例如 `2026-5-25`）；已明确使用短日期的展示点保持 `M-D`（例如 `5-25`）；时间展示固定为 `HH:mm`（例如 `16:25`）；默认日期时间展示为 `YYYY-M-D HH:mm`。
- 所有瞬时时间均按 `Asia/Shanghai`（北京时间）计算及展示。无时区的日期字符串（`YYYY-MM-DD`、`YYYYMMDD`）是业务日历日期，不得因时区转换而改变日历日；数据库无时区日期时间继续按北京时间墙上时间解释。
- 日期选择控件和 API 的既有机器可读传输格式保持兼容（如 `YYYY-MM-DD`、`YYYYMMDD`）；本需求只改变人可读显示及“今天/当前时刻”计算。
- 需求、任务范围及影响分析均已完成并为 `ready`；实施中若发现新的格式语义或跨模块影响，先更新本文与任务范围再继续。

## 1. 目标与业务价值

- 要解决的问题：相同日期/时间在不同页面存在补零、秒数、浏览器本地时区和 UTC 截断等不一致；部分服务端“今天”计算会在北京时间跨日附近写入错误日期。
- 预期结果：全系统人可读日期只有默认 `YYYY-M-D` 与经明确保留的短日期 `M-D` 两种；时间只有 `HH:mm`；所有当前日期、日程判断和显示均使用北京时间。
- 业务价值：用户在列表、详情、审计、附件、配置和自动任务中获得一致、可预测的时间口径，避免跨日错记及时间沟通错误。

## 2. 使用者与场景

| --- | --- | --- | --- | --- |

| 配置管理员 | 设置投产日期或每日同步时间 | 具有系统设置权限 | 使用日期控件、查看同步时刻 | 日期展示一致，时间仅显示到分钟 |
| 运行人员 | 北京时间跨日附近执行服务 | 有本地脱敏运行环境 | 创建记录、生成默认日期、触发每日同步 | 写入和计划判断使用北京时间，不出现 UTC 前一天/后一天 |

## 3. 范围

### 本次要做

1. 建立前端和服务端可复用的北京时间日期/时间工具；集中处理 ISO 瞬时值、无时区数据库日期时间和纯业务日期，禁止页面或路由自行截取 UTC 日期。
2. 全面盘点 `web/src`、`server/src` 和运行脚本中人可读格式化、当前日期/时间及每日计划计算，迁移到统一工具或保留有文档注释的短日期格式。
3. 将当前日期写入、审批/测试/投产默认日期、每日同步调度及相关校验统一为北京时间；不改变既有字段的机器可读格式或合法值。
4. 将审计、附件、概览、投产详情、表格、表单、筛选、设置和动态配置控件的人可读日期/时间统一为规定格式；明确短日期仅用于现有紧凑签署/卡片位置。
5. 为北京时间跨日、带时区 ISO、无时区日期时间、纯日期、默认格式、短日期和 `HH:mm` 增加自动化覆盖；进行桌面及移动端浏览器验收。

### 明确不做

1. 不迁移、修改或回填任何数据库日期/时间数据，不变更列类型、索引或 API DTO。
2. 不新增或调整输入项、交付件、权限、审计事件、外网接口或第三方时区服务。
3. 不改变业务字段传输/存储的 `YYYY-MM-DD`、`YYYYMMDD`、ISO 8601 或数据库既有无时区格式；这些不是用户展示格式。
4. 不修改与业务日期无关的编号模板、密码过期安全判断或测试夹具，除非盘点证明其直接使用了错误的“当前北京日期/时间”口径。

## 4. 行为与业务规则

- 当前行为：前端已有部分 `formatBeijingDateTime`，但默认包含秒数；多个路由以 `toISOString().slice(0, 10)` 取 UTC 日期；日期时间控件、附件/审计和紧凑详情存在不同格式，日常调度使用进程本地时区。
- 变更后行为：显示层统一经日期时间工具输出，业务纯日期不转换日历日；所有“当前日期/当前时间/按日调度”使用 `Asia/Shanghai`。
- 失败行为：无效或空日期时间显示既有占位符 `—`，不抛出页面异常；无法解析的输入不得被静默当作当前时间写入。

| 规则编号 | 触发条件 | 业务规则 | 不满足时处理 |
| --- | --- | --- | --- |
| BR-001 | 默认展示一个日期 | 输出 `YYYY-M-D`，不补月/日零 | 统一工具返回 `—`，调用点不得自行格式化 |
| BR-002 | 明确标记为紧凑短日期的位置 | 仅输出 `M-D`，不包含年份 | 其他位置不得使用短日期 |
| BR-003 | 展示一个时间或日期时间 | 时间仅为 24 小时制 `HH:mm`；默认日期时间为 `YYYY-M-D HH:mm` | 不展示秒数、AM/PM 或浏览器本地时区结果 |
| BR-004 | 解析带 `Z` 或 offset 的 ISO 瞬时值 | 转换为北京时间后再展示或计算 | 解析失败显示 `—`，不回退为系统当前时间 |
| BR-005 | 解析无时区日期时间 | 作为北京时间墙上时间展示，不二次偏移 | 不能以浏览器/服务器本地时区重新解释 |
| BR-006 | 计算今天、默认日期或每日计划 | 使用 `Asia/Shanghai` 的日历日和分钟 | 禁止用 UTC 字符串截取或主机本地时区代替 |
| BR-007 | 日期选择/接口写入 | 保持既有机器可读格式与服务端校验兼容 | 不因显示格式改变 API 字段值 |
